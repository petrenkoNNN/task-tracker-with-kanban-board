# Innotech Workspace Kanban

Веб-приложение для управления задачами команды по методологии Kanban.

Проект реализует полный цикл командной работы: создание рабочих пространств, проектов, задач, назначение исполнителей, управление чек-листами, комментариями, вложениями и историей действий.

---

# Возможности

## Авторизация пользователей

* регистрация аккаунта;
* вход и выход из системы;
* поддержка пользовательских сессий.

## Рабочие пространства (Workspace)

* создание рабочего пространства;
* добавление участников по логину;
* разграничение доступа между пользователями.

## Проекты

* создание нескольких проектов внутри одного рабочего пространства;
* разделение задач по направлениям работы.

## Kanban-доска

Поддерживаются основные этапы работы:

* К выполнению
* В работе
* На проверке
* Готово

## Управление задачами

Для каждой задачи доступны:

* название;
* описание;
* исполнитель;
* приоритет;
* дедлайн;
* теги;
* чек-лист;
* комментарии;
* вложения;
* история изменений.

## Работа с файлами

Поддерживается загрузка материалов в задачу.

Файлы сохраняются локально в директории `uploads`.

## Отложенные задачи

Можно временно убрать задачу с активной доски, указав причину переноса, а затем вернуть её обратно.

# Подготовка окружения

## Требования

Необходимо установить:

* Node.js 20+
* Docker Desktop
* Docker Compose

Проверка:

```bash
node -v
npm -v
docker -v
docker compose version
```

---

# Настройка проекта

Установить зависимости:

```bash
npm install
```

Создать файл окружения:

```bash
cp .env.example .env
```

Содержимое:

```env
DATABASE_URL=postgres://kanban:kanban@127.0.0.1:55432/kanban
PORT=5173
```

---

# Запуск проекта

## 1. Запустить PostgreSQL

```bash
docker compose up -d db
```

Проверить контейнер:

```bash
docker ps
```

## 2. Запустить приложение

```bash
npm run dev
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:5173
```

---

# Запуск без PostgreSQL

Для локального тестирования доступен резервный режим с JSON-хранилищем.

```bash
npm run dev:json
```

Этот режим используется только для упрощённой проверки функциональности.

# Сценарий демонстрации проекта

## Шаг 1

Зарегистрировать нового пользователя.

После регистрации автоматически создаются:

* рабочее пространство «Мой workspace»;
* проект «Канбан».

## Шаг 2

Создать второго пользователя.

Вернуться в аккаунт владельца и добавить нового пользователя в рабочее пространство по логину.

## Шаг 3

Создать новую задачу.

Заполнить:

* название;
* описание;
* исполнителя;
* приоритет;
* срок выполнения;
* тег.

## Шаг 4

Добавить чек-лист.

Например:

* разработать интерфейс;
* протестировать функционал;
* подготовить документацию.

## Шаг 5

Прикрепить файл к задаче.

Показать сохранение материала.

## Шаг 6

Добавить комментарий.

Продемонстрировать историю изменений.

## Шаг 7

Попробовать завершить задачу при невыполненном чек-листе.

Система должна заблокировать закрытие задачи.

## Шаг 8

Выполнить чек-лист.

Переместить задачу в колонку «Готово».

## Шаг 9

Отложить задачу, указав причину.

Перейти в раздел отложенных задач и вернуть её обратно на доску.

---

# Особенности реализации

* пользователь работает только в тех рабочих пространствах, где является участником;
* история действий сохраняет изменения внутри задач;
* вложения привязываются непосредственно к задачам;
* чек-лист предотвращает преждевременное закрытие задачи;
* система поддерживает несколько проектов внутри одного рабочего пространства.
